# MR-review Skill

This skill performs code review and bug detection on pull requests or code changes.

## Usage

Use this skill when reviewing merge requests or when you want to analyze code for potential issues.

## What it does

1. **General Code Review**
   - Checks code quality and structure
   - Identifies code smells
   - Suggests improvements for readability and maintainability

2. **Bug Detection**
   - Looks for common bug patterns
   - Identifies potential null/undefined issues
   - Catches logic errors
   - Finds security vulnerabilities

3. **Suggestions**
   - Provides actionable improvement suggestions
   - Recommends best practices
   - Suggests refactoring opportunities
