# /summary Skill

This skill summarizes file contents and conversations.

## Usage

Use `/summary` command to get a concise summary of files or conversation context.

## What it does

1. **File Summarization**
   - Provides overview of file contents
   - Identifies key functions/classes/modules
   - Highlights important sections
   - Explains what the code does in plain terms

2. **Conversation Summarization**
   - Summarizes recent messages
   - Extracts key decisions made
   - Lists action items or tasks
   - Provides context for follow-up questions

3. **Output Format**
   - Concise bullet points
   - Key takeaways
   - Relevant code snippets when helpful
